# claude-do

فایل رو بده به کلاد، کلاد همون کاری رو می‌کنه که فایل گفته.

یک فایل متنی یا مارک‌داون بنویس و توش بگو چی می‌خوای. کلاد داخل یک پوشه‌ی محدود
فایل می‌خونه، فایل می‌نویسه و دستور اجرا می‌کنه تا کار تموم بشه.

## نصب

```bash
pip install -e .
export ANTHROPIC_API_KEY="your-key"
```

## استفاده

```bash
claude-do examples/task.md --dir ./work
```

| گزینه | کار |
|---|---|
| `--dir` | پوشه‌ای که کلاد فقط داخل اون کار می‌کنه |
| `--model` | مدل دلخواه |
| `-y` | اجرای دستورها بدون پرسیدن |

## ساختار

```
claude_do/__init__.py   خط فرمان
claude_do/core.py       ابزارها و حلقه‌ی کلاد
examples/task.md        فایل نمونه
pyproject.toml          بسته‌بندی
```

## امنیت

- کلاد از پوشه‌ی `--dir` بیرون نمی‌تونه فایل بخونه یا بنویسه.
- هر دستور شل قبل از اجرا از تو تأیید می‌گیره، مگر با `-y`.
